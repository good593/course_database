# Redis 입문 강의자료

처음 Redis를 배우는 학생을 위한 12차시 강의자료입니다. 명령어를 단순히
암기하기보다, 문제에 맞는 자료구조를 선택하고 작은 기능을 직접 구현하는 데
초점을 둡니다.

## 강의 개요

- 대상: Redis를 처음 접하는 학생
- 권장 시간: 차시당 2시간, 총 24시간
- 선수 지식: 데이터베이스 기초, 터미널 사용법, Python 기초
- 실습 환경: Redis 7 이상, `redis-cli`, Python 3.10 이상
- 수업 사례: 쇼핑·커뮤니티 서비스의 캐시, 조회수, 랭킹, 큐 구현

## 학습 목표

수강 후 학생은 다음을 수행할 수 있습니다.

1. Redis의 특징과 관계형 데이터베이스와의 차이를 설명합니다.
2. String, List, Set, Sorted Set, Hash를 상황에 맞게 선택합니다.
3. TTL을 적용한 캐시와 세션을 구현합니다.
4. Python 애플리케이션에서 Redis를 사용합니다.
5. 영속성, 메모리 정책, 복제, 보안의 기본 원리를 설명합니다.
6. Redis를 활용한 작은 서비스를 설계하고 구현합니다.

## 실습 환경 준비

Docker가 설치되어 있다면 다음 명령으로 실습 서버를 실행할 수 있습니다.

```bash
docker run --name redis-class -p 6379:6379 -d redis:7-alpine
docker exec -it redis-class redis-cli
```

연결을 확인합니다.

```redis
PING
```

`PONG`이 출력되면 준비가 끝났습니다. 수업이 끝난 뒤 컨테이너를 중지하거나
다시 시작할 수 있습니다.

```bash
docker stop redis-class
docker start redis-class
```

> `FLUSHALL`과 `FLUSHDB`는 데이터를 삭제합니다. 수업용 서버에서만 사용하고,
> 공유 서버나 운영 서버에서는 실행하지 않습니다.
